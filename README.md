# PICKPLAY

가상 포인트로 즐기는 스포츠 승부예측 게임입니다. 실제 현금 충전·환전·출금 기능이 없으며, 실제 금전적 이익과 무관한 오락용 서비스입니다.

- `index.html` — 플레이 화면 (닉네임 생성 → 가상 포인트 10,000P로 시작 → 축구/야구/e스포츠 경기 예측 → 리더보드/내 기록)
- `admin.html` — 관리자 화면 (경기 등록/수정/삭제, 결과 확정 시 자동 정산, 포인트 지급/차감, 베팅 취소, 시작 포인트·베팅 한도 설정, 전체 초기화)

두 페이지는 같은 오리진에서 서빙될 때 `localStorage`를 공유합니다. 서버/DB가 없는 프런트엔드 전용 데모이며, 실제 서비스로 확장하려면 실시간 경기 결과 API와 회원 계정/서버 기반 저장소 연동이 필요합니다.

## 배포

`main` 브랜치에 푸시되면 GitHub Actions가 저장소 루트를 GitHub Pages로 배포합니다 (`.github/workflows/pages.yml`).
